# Royal Haven Hotel Customer Service Chatbot

A GPT-powered customer service chatbot built with Python and the OpenAI API to simulate customer support for a fictional hotel.

## Project Overview

The Royal Haven Hotel Customer Service Chatbot answers common guest questions using natural language. It provides information about hotel services while maintaining conversation context for follow-up questions.

## Features

- Answers common hotel FAQs
- Understands natural-language questions
- Maintains conversation history
- Understands follow-up questions
- Provides short and professional responses
- Avoids inventing information outside its knowledge base
- Directs customers to the front desk when information is unavailable

## Hotel Information Covered

The chatbot answers questions about:

- Check-in and check-out
- Breakfast
- Wi-Fi
- Parking
- Pet policy
- Swimming pool
- Gym
- Cancellation policy
- Room service

## Technologies Used

- Python
- OpenAI API
- GPT
- Visual Studio Code
- python-dotenv

## Example Conversation

User: What time does the swimming pool open?

Agent: The swimming pool opens at 7:00 AM.

User: When does it close?

Agent: The swimming pool closes at 9:00 PM.

This demonstrates the chatbot's ability to maintain conversation context and understand follow-up questions.

## Handling Unknown Information

When asked about information outside its knowledge base, such as current room prices or availability, the chatbot does not invent an answer. Instead, it directs the customer to contact the hotel front desk.

## Future Improvements

Future versions could be connected to a hotel database or reservation system to provide real-time room prices, availability, and booking information.
